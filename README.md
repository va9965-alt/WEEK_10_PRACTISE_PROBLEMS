# Week 10 Practice Problems

Five standalone Java programs for the practice problems.

## Requirements

- JDK 8 or later
- VS Code with the Extension Pack for Java (optional)

## Run a program

Open a terminal in this folder, compile the program, and run its class:

```powershell
javac Question1.java
java Question1
```

Replace `Question1` with `Question2`, `Question3`, `Question4`, or `Question5` to run another problem. Each program reads input from the terminal.

## Programs

1. `Question1.java` counts vowels and consonants in a word.
2. `Question2.java` reverses a word and checks whether it is a palindrome.
3. `Question3.java` counts even and odd integers. Enter integers separated by spaces, commas, or brackets, for example `[3, 8, 12, 5, 7, 10]`.
4. `Question4.java` reverses an integer array in place. Enter integers separated by spaces, commas, or brackets, for example `[11, 22, 33, 44]`.
5. `Question5.java` prints the sum of a positive integer's digits and the reversed number.
